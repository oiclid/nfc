# NFC Cooperative Management System

Desktop application for managing cooperative society operations —
savings, loans, dividends, and financial reporting.

## Setup

```bash
pip install -r requirements.txt
python migrations/migrate.py     # one-time: builds nfc_cooperative.db from database.sld
python main.py
```

## First launch

The app detects an empty users table and shows a setup wizard to create
the initial admin account.

## Running tests

```bash
pytest test_database.py -v
```

## Project structure
